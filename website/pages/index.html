OxideBSD

OxideBSD is a 4.4BSD-Lite inspired operating system with a kernel written in Rust and a userland and libc also being written in Rust (outside of ports). While it is not directly descended from any BSD operating system, it aspires to have a unique identity as a close BSD cousin written from scratch, although it currently has major ported dependencies. OxideBSD aims to eventually be a usable desktop operating system like a Linux distro or a BSD descendant.
