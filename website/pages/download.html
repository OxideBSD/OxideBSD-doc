Download

There are no prebuilt images yet; OxideBSD is built from source and run in QEMU.

Source

git clone --recurse-submodules https://github.com/OxideBSD/OxideBSD.git

Releases are tagged (v0.2.0 is the latest); master is where work happens. Design documents are in OxideBSD-doc.

Requirements

  • A C compiler (clang or gcc) with musl support
  • GNU make
  • Rust nightly (the exact version is pinned in rust-toolchain.toml; rustup picks it up)
  • QEMU, and OVMF firmware for UEFI boot

Build and run

cargo run

This builds the kernel and userland, stages a bootable ISO and boots it in QEMU. The first build is slow: it builds BusyBox, musl and a Clang/LLVM toolchain from source.
